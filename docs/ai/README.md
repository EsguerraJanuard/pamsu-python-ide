# PAMSU AI Continuity Pack

Place this folder in the repository as `docs/ai/`.

Files:
- `PROJECT_CONTEXT.md` — permanent domain, security, privacy, and architecture rules
- `ROADMAP.md` — canonical Pillars 1–16 and final release sequence
- `WORKFLOW.md` — communication, coding, testing, and Git workflow
- `CURRENT_HANDOFF.md` — current verified state and next exact step
- `GEMINI_BOOTSTRAP_PROMPT.md` — master prompt to paste into Gemini

Every AI assistant must read the four repository context files before implementing code.
